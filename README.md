# Shield Global Group Website

A modern, enterprise-grade corporate website built for **Shield Global Group**, showcasing the company's global presence, services, industries, and international operations.

The website is designed with a strong focus on performance, accessibility, SEO, responsive design, and user experience while maintaining a clean corporate identity.

---

## Features

- Modern enterprise UI
- Fully responsive design
- Internationalization (i18n) support
- SEO optimized
- High performance
- Accessible UI components
- Interactive Global Presence map
- Smooth animations
- Mobile-first design
- Reusable component architecture

## Installation

Clone the repository

```bash
git clone https://github.com/your-org/shield-global-group.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

## Build

Create a production build

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
